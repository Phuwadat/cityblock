# HIGHWATER — The Last Rooftop

Play: https://phuwadat.github.io/cityblock/?v=0.5.0

## Version 0.5.0

- Three-player, player-hosted online rooms with a shareable join code through Unity MPS and Relay over WSS.
- Three rounds, shared floodwater and events, authoritative placement/scoring, ready checks and spectator views.
- A closer camera centred on your own tower, with smooth following and an overview of surviving friends after elimination.
- CPU opponents for a quick offline test. Browser players use online room codes; LAN is available only in desktop builds.
- Existing storybook intro, Thai/English typography, cozy music, expanding Perfect combos and detailed neighbourhoods.

Choose Play with friends, create a room and share the code with two friends using this same version. All three players ready up; the host starts. Keep the host's game open. Leaving the host closes the room.

SPACE / tap: place a block. 1–3: choose an upgrade. F1–F4: emotes. P / ESC: settings during online play (the match continues).

Unity 6 Web build with gzip decompression fallback for GitHub Pages. The gh-pages branch publishes the site. Unity source and Editor caches stay local. Font and SDK notices are included in LICENSES.
